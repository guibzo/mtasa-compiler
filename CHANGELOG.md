# Change Log

All notable changes to the "mtasa-resource-script-compiler" extension will be documented in this file.

## [0.2.0]

- Bundled the MTA compiler for local Windows and Linux compilation.
- Avoided one API request per file on supported platforms.

## [0.1.0]

- Added resource output generation in `_compiled`.
- Added wildcard support and selection-aware compilation.
- Added compatibility with Cursor through the VS Code extension API.
- Refactored compilation into reusable services.
